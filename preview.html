Inkstone 디자인 시스템

썸네일·영상·숏폼용 차분한 인포그래픽 시스템. 돌색 바탕 + 잉크 + 인디고 한 가지. 정본은 DESIGN.md예요.

시스템 1:1 썸네일 16:9 영상 9:16 숏폼 실전 사례

원칙

모든 판단은 이 다섯 줄로 돌아온다.

01한 장, 한 메시지제목 하나 + 핵심 그림 하나 + 보조 정보 2~4개.
02색은 의미에만무채색이 대부분. 인디고는 초점 1~2곳, 상태색은 상태에만.
03글보다 구조흐름·비교·숫자·화면으로 보여 주고 글은 이름표로.
04선과 면으로 위계그림자 대신 2px 선과 면 색. 떠 있는 것만 그림자.
05꽉 차되 숨 쉬게정보 단위 4~7개, 빈 곳은 화면의 30~40%.

색

값은 ds.css 변수에서 그대로 읽어 와요. 바탕 대비 글자색은 모두 4.5:1 이상.

글자

Pretendard Variable(한글·영문) + Geist Mono(영문 꼬리표·코드). 크기는 짧은 변 1080px 캔버스 기준이고, 여기서는 절반으로 줄여 보여 줘요.

아이콘·로고

선 아이콘 Lucide(선 두께 1.75), 브랜드 로고 Simple Icons(단색). <i data-icon="이름">, <i data-logo="이름"> 으로 써요.

브랜드 로고

컴포넌트

캔버스 크기 그대로 만든 부품 시트예요. 클래스 이름이 이름표에 적혀 있어요. 시트를 누르면 모션을 다시 재생해요.

템플릿 결과물

npm run render:all 로 만든 파일이에요. 각 템플릿 페이지에서 직접 고쳐 다시 내보내요.
